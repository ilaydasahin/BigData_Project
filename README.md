# Big Data Processing & Exploratory Data Analysis

A collection of PySpark and Pandas data processing notebooks designed for large-scale dataset analysis and statistical evaluation.

## Overview

This repository contains data engineering and exploratory data analysis (EDA) workflows. It focuses on cleaning structured datasets, distributed transformations, aggregation statistics, and visual insights.

## Technologies & Libraries

- Processing Engines: PySpark, Pandas, NumPy
- Data Visualization: Matplotlib, Seaborn
- Runtime Environment: Jupyter Notebook / JupyterLab

## Setup & Running

1. Create a virtual environment:
   python -m venv venv
   # On Windows: venv\Scripts\activate

2. Install dependencies:
   pip install -r requirements.txt

3. Start Jupyter Notebook:
   jupyter lab
